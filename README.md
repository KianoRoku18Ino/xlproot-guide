# XLProot Guide

A beginner-friendly, device-agnostic field guide to running a full Linux desktop on Android inside a PRoot container — built on XoDos-Ark.

**Live guide:** https://kianoroku18ino.github.io/xlproot-guide/

## What's in here

Prerequisites, install steps for Debian + XFCE4 + X11 via Termux-X11, the Android banking-app / Developer Options conflict nobody warns you about, known architectural limits of PRoot on Android, and a troubleshooting workflow.
